# 🤖 V.I.S.I.O.N — Guide Complet des Commandes

> **Mot d'activation** : Dites **"Vision"** pour démarrer une session, puis parlez naturellement.
> **Fin de session** : Dites *"merci"*, *"au revoir"* ou *"repos"*.

---

## 🎙️ Activation & Session

| Commande                                    | Effet                          |
| ------------------------------------------- | ------------------------------ |
| `"Vision"`                                | Active la session              |
| `"Vision, [commande]"`                    | Active + exécute directement  |
| `"Merci"` / `"Au revoir"` / `"Repos"` | Met en veille                  |
| `"Tais-toi"` / `"Silence"`              | Coupe la parole immédiatement |

---

## 💡 Domotique — Lumières

| Commande               | Exemple                                                        |
| ---------------------- | -------------------------------------------------------------- |
| Allumer une pièce     | `"Allume le salon"`                                          |
| Éteindre une pièce   | `"Éteins la cuisine"`                                       |
| Changer la couleur     | `"Mets le salon en rouge"` / `"en bleu"` / `"en violet"` |
| Régler la luminosité | `"Mets le bureau à 50%"`                                    |
| Tout allumer/éteindre | `"Allume toutes les lumières"`                              |

**Pièces disponibles :** salon, plafond salon, canapés, lampadaire, lampe de chevet, cuisine, bureau, PC, chambre parentale, plafond chambre
**Couleurs :** rouge, bleu, vert, blanc, orange, violet, rose, jaune, cyan, or, argent, lavande, corail, turquoise...

## 📝 Notes

- Les commandes sont **naturelles** — vous n'avez pas besoin de formules exactes, l'IA comprend le sens.
- En cas de panne internet, les calculs, conversions, heure et date fonctionnent **hors-ligne**.
- Le **mode Iron Man** permet de contrôler les lumières du salon par double applaudissement.
